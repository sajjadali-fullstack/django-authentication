# 🎓 Sajjad Exams - Online Examination Portal

An easy-to-use, secure, and responsive Online Examination Portal built with Python, Django, and Bootstrap 5. This platform allows students to register, log in, read exam instructions, and take tests securely.

---

## ⚡ Key Features

- **Secure Login & Registration:** Built-in Django user authentication with a clean, custom user interface.
- **Hidden Passwords:** Passwords are completely hidden (`••••••`) while typing on the sign-up form for extra privacy.
- **Smart Navigation Bar:** The menu bar automatically changes based on whether a user is logged in or logged out.
- **Protected Exam Pages:** Students cannot access the exam pages (Python, Java, Aptitude) without logging in first.
- **Clean Rules & Instructions:** A professional, easy-to-read rules layout on both the Home and Logout pages using Bootstrap grids and alerts.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, Bootstrap 5 (CSS framework)
- **Database:** SQLite (Default)
